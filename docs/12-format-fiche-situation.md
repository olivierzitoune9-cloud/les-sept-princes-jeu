# 12 - Format de fiche Situation

Une fiche decrit une possession dans l ordre du texte. Elle ne transforme pas une sequence en bouton et n invente pas les informations absentes.

## Fiche

- Identifiant : `S-XXX`
- Source : chapitre et passage
- Score et temps :
- Equipe en possession :
- Porteur et position :
- Defense en place :
- Intervalles : ouverts, fermes, en creation
- Etat physique et mental visible :

### Informations disponibles

- Ce que voit l attaque :
- Ce que voit la defense :
- Ce qui reste cache :
- Hypotheses ou incertitudes : `[TROU]` si necessaire

### Decision du porteur

- Deplacement : forme, direction, cible et timing
- Intention :
- Action :
- Cible : joueur ou zone
- Execution :

### Partenaires sans ballon

- Course ou appel :
- Bloc ou croise :
- Entree ou sortie du pivot :
- Permutation :
- Effet sur les espaces :

### Defense

- Joueurs concernes :
- Rester, sortir, coulisser, aider, changer, fermer ou intercepter :
- Declencheur conditionnel visible :
- Zone abandonnee :
- Anticipation :

### Gardien

- Position : ligne ou avance
- Lecture : premier poteau, deuxieme poteau, haut, bas, lob ou autre
- Reponse :
- Duel mental observable :

### Resolution

- Ordre des evenements :
- Resultat : but, arret, poteau, interception, faute ou perte
- Cause precise :
- Consequence spatiale :
- Consequence fatigue ou mentale :
- Pattern revele ou modifie :
- Nouvelles options pour la suite :

## Regles de redaction

- Toujours decrire verbe, cible et timing, pas seulement « tir » ou « passe ».
- Toujours noter l intervalle attaque et son etat avant et apres.
- Ne jamais ajouter pouvoir magique, ame, representation animee ou element non source.
- En cas de texte elliptique, marquer `[TROU]` et proposer deux hypotheses compatibles sans trancher.
